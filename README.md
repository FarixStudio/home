# Farix

**You describe the workflow. We automate it.**

Farix builds custom software for AEC (architecture, engineering and construction) teams: Revit add-ins, Windows applications and focused scripts, all shaped around how your team actually works instead of forcing you to adapt to generic tools.

🌐 **Live website:** https://luffyxda.github.io/Farix/

## About the website

This repository is the official Farix website. It's a single-page site that explains what Farix does, shows proof of work, and makes it easy for AEC teams to get in touch.

### Who it's for

AEC firms, BIM teams and engineers who:

- repeat the same manual model work on every project,
- follow internal rules and standards that off-the-shelf plugins don't cover,
- don't have an in-house developer but need a working tool, not a research project.

| Section | What it says |

### Tools featured as proof of work

| Tool | What it does |
|---|---|
| **Planger** | Places hangers on pipes with spacing rules, sizing and rod length to structure above. Modeless, so the engineer keeps working. |
| **Czer** | Analyzes conduit runs and bend angles, flags runs over 360°, and helps isolate issues instead of manual tracing. |
| **ParamSync** | Copies parameter values across a selection or category. Built for workshared models and large element sets. |
| **Rodex** | Pulls room parameters and items from the host and linked models into structured Excel for documentation handoff. |

These tools show what Farix can do. Client projects may look completely different.
