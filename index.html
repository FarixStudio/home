Process

Talk first. Build second.

No product catalog to force-fit. We start from your requirement.

1

You explain the pain

What takes too long, what breaks, what must match company standards. Screenshots, sample models, or a short call are enough.

2

We scope the automation

Revit API add-in, standalone Windows app, batch tool, or a mix. Clear outcomes, not vague “AI magic.”

3

We build & iterate

Working software against your real files. You try it; we refine until it fits the daily workflow.

4

You own the result

Installer, training notes, and a tool your team can run without us in the room.

Revit add-in MEP supports

Planger

Places hangers on pipes with spacing rules, sizing, and rod length to structure above — modeless so the engineer keeps working.

Revit add-in Electrical QA

Czer

Analyzes conduit runs and bend angles, flags runs over 360°, and helps isolate issues instead of manual tracing.

Copies parameter values across selection or category — built for workshared models and large element sets.

Revit add-in Room data

Rodex

Pulls room parameters and items from host + linked models into structured Excel for documentation handoff.
